- 작성일: 2026-08-25
- 분석 대상: **UNLABEL** (주식회사 메인월드, [unlabel.ai](https://unlabel.ai/)) — 가공식품 라벨 스캔·첨가물 분석 앱
- 분석 재료: 앱 스크린샷 19장(온보딩~커뮤니티 전 화면), 인스타그램 @ggabalggabal 지표, ZERO DOT(CUBED_v2) 코드베이스 전수 조사

## 0. 요약 (TL;DR)

1. **Unlabel은 "넓고 얕은" 범용 첨가물 스캐너, ZERO DOT은 "좁고 깊은" 혈당·당류 수직 특화.** 정면 충돌이 아니라 축이 다르다. 축을 지키면서 Unlabel의 잘하는 것(온보딩 개인화, 스캔 히스토리, 카테고리 브라우징, 긍정/부정 균형 리포트, 공유 동선)만 선별 이식하는 것이 맞다.
2. **Unlabel의 최대 무기는 커버리지(코리안넷 추정 바코드 DB)와 인스타 바이럴, 최대 약점은 근거 불투명한 100점 점수와 성급한 유료화**(무료 스캔 7회 제한, 월 5,800원)다. 커뮤니티에 이미 "이 어플 유료임 무료임?", 데이터 품질 불만 글이 올라와 있다. 우리는 반대로 **무료 + 근거 투명(룰북 공개) + 커버리지 부트스트랩**으로 치고 들어간다.
3. **마케팅은 포맷을 통째로 벤치마킹할 가치가 있다.** AI 제품 의인화 캐릭터 + "TOP 4 (N편)" 시리즈물 + 폭로 훅으로 게시물 5개 만에 팔로워 2.2만, 최고 조회수 195만을 만들었다. 우리는 같은 포맷에 **"제로의 배신" 시리즈**(무설탕인데 혈당 주의 제품)를 얹되, "속였다" 같은 비방 표현 대신 **표시정보 수치 인용 팩트체크 톤**으로 법적 리스크를 제거한다. 랜딩페이지 + 출시 알림 수집 인프라가 이미 있어 퍼널이 바로 연결된다.

## 1. Unlabel 관찰 기록 (사실 정리)

### 1.1 제품 구조

| 영역 | 관찰 내용 |
|---|---|
| 포지셔닝 | "식품 라벨은 생각보다 친절하지 않아요 — 성분표를 읽고 중요한 것만 정리" |
| 온보딩 | **로그인 전 7단계 설문**: ①성별 ②생년월일 ③가공식품 섭취 빈도 ④최대 관심사(첨가물/당류/칼로리/단백질/아이·가족) ⑤식단(비건/채식/키토/카니보어) ⑥신경 쓰는 성분(락토프리/글루텐프리/씨앗기름) ⑦알레르기(법정 알레르기 유발물질 15+종). 전부 skip 가능 → 설문 후 카카오/구글 로그인 → "맞춤 설정 준비 중 95%" 연출 로딩 |
| 스캔 | 바코드 스캔 / 사진 스캔 토글. 인식 즉시 하단에 제품카드+점수 표시, **"이 제품이 아닌가요?"** 정정 링크. **무료 7회 제한** 문구가 스캔 화면에 상시 노출 |
| 홈 | 배너 캐러셀, **최근 본 제품**, 제품 종류 브라우징(음료/과자/유제품/단백질/조미료/냉동식품/라면), 5탭(홈/검색/스캔/커뮤니티/프로필) |
| 제품 상세 | **0~100 건강 점수** 원형 게이지(신라면 13점, 웰치 제로 27점) + **원산지**(제조국 + 원재료별 국기: 소맥분 미국·호주산, 팜유 말레이시아산) + **"아쉬워요/좋아요" 2축 리포트**(첨가물 5개·지방 품질·나트륨 1930mg·칼로리 505kcal ↔ 단백질 10g) + 120g(1회분) 기준 토글 + 첨가물 인라인 설명 |
| 첨가물 사전 | 성분별 상세 페이지: 쉬운 설명, **첨가물 점수 1~4 색상 스케일**(높은 주의→주의 없음), 위험성/이점, **참고문헌**, **첨가물 신고하기**. 하단 면책: "이 평가는 식품 표시 정보를 바탕으로 한 참고 정보예요" |
| 커뮤니티 | 게시판(홈/키토/정보/자유) + 좋아요순 인기글. 인기글 좋아요가 1~6개 수준으로 **아직 유령도시**. 상위 글이 "제품 검색하면 정보 나오긴 하는데…", "PM 자르세요 사장님 제발", "이 어플 유료임 무료임?" — 데이터 품질·유료화 불만이 이미 표면화 |
| 수익화 | **UNLABEL PRO 구독**: 연간 ₩4,000/월(정가 5,800, 얼리버드 31%↓) / 월간 ₩5,800/월(정가 10,800, 46%↓), 7일 무료 체험. 무료 vs 유료 비교표에서 무료는 "첨가물 상세 분석"뿐, **맞춤 성분 경고·건강 점수·무제한 스캔이 전부 유료**. "하루 133원/193원" 프레이밍 |

### 1.2 데이터 출처 (추정)

바코드 스캔 즉시 제품명·제조사·표시정보가 뜨는 것으로 보아 **코리안넷(유통상품지식뱅크) 상품 DB 구매 또는 식약처 바코드연계제품정보 계열 공공 데이터** 기반으로 추정된다(사용자 판단과 동일). 원산지·첨가물 목록은 식품 표시정보에서 파싱한 것으로 보이며, 자체 실측이 아닌 표시정보 의존임을 면책 문구로 인정하고 있다.

### 1.3 인스타그램 지표 (@ggabalggabal "까발려주마")

| 항목 | 값 |
|---|---|
| 게시물 / 팔로워 | **5개 / 2.2만** (팔로잉 1) |
| 조회수 | 1편 195.3만 · 2편 32.6만 · 3편 24.1만 · 4편 32.4만 · 5편 30.3만 |
| 포맷 | AI 생성 3D **제품 의인화 캐릭터** 릴스. 편의점·목장 배경, 상단 빨간 타이틀 박스 "대기업이 속인 제품 TOP 4 (N편)", 하단 1인칭 자백 자막("난 bhc야!", "나는 롯데") |
| 계정 전략 | 앱 브랜드 계정이 아니라 **"까발려주마" 폭로 페르소나 계정**. 프로필에 "AI 크리에이터" 표기 + 앱 다운로드 유도 + unlabel.ai 링크 1개 |

**해석**: 조회수가 팔로워의 10~90배 → 릴스 탐색(추천) 트래픽 의존형. 시리즈 넘버링(N편)이 팔로우 동기를 만들고, AI 제작이라 게시물당 제작비가 매우 낮다. 다만 "대기업이 **속인**"이라는 단정 표현과 실제 제품 패키지를 본뜬 캐릭터는 명예훼손·상표권 리스크를 안고 있는 공격적 운영이다.

## 2. 벤치마킹 — 도입할 것, 고칠 것, 하지 말 것

### 2.1 새로 도입할 기능

| # | 항목 | Unlabel에서 배울 점 | ZERO DOT 적용안 | 근거/기존 자산 |
|---|---|---|---|---|
| 1 | **최근 분석 기록(스캔 히스토리)** | 홈 상단 "최근 본 제품"이 재방문의 기본기 | 분석 결과를 자동 히스토리로 저장(로컬 우선), 홈에 가로 카드로 노출. 현재는 수동 "먹은 기록"만 있어 조회 이력이 증발한다 | `product_logs` 스키마 확장 또는 클라이언트 캐시 |
| 2 | **결과 공유 카드** | 제품 상세에 공유 버튼 상시 배치 → 점수 스크린샷이 밈처럼 도는 구조 | "라벨은 0g → 혈당은 ↑" 반전 스트립 + 신호등 + 각설탕 환산을 담은 **이미지 카드 공유**. §4 마케팅 루프의 전제조건 | `VerdictHero` 위젯 재활용, share_plus 추가 |
| 3 | **카테고리 브라우징** | 홈의 제품 종류 그리드(음료/과자/유제품…)로 스캔 없이도 탐색 가능 | 검색 화면에 카테고리 18종 그리드 + 등급/순탄수 정렬 추가. "검색해야만 나오는 앱"에서 "구경하는 앱"으로 | `category_meta` 18종 이미 존재 |
| 4 | **경량 온보딩(1~2문항, skip 가능)** | 설문→로그인 순서(매몰비용 후 가입 요구)와 "왜 필요한가요?" 설명, 95% 연출 로딩까지 전환 설계가 정교 | 7단계는 과하다. **"관리 목적이 뭐예요?"(혈당 관리/체중 관리/습관 개선) 1문항**만 받고 verdict 문장 톤·기준에 반영. 제거됐던 개인화 판정 설계(혈당 5%/체중 7.5%/일반 10%)를 이 답변과 연결해 복원 | `docs/superpowers/specs/2026-08-19-sugar-personal-verdict-design.md` (커밋 72c94a9에서 제거됨) |
| 5 | **"제품이 다른가요?" 정정 UX** | 오인식을 사용자가 즉시 바로잡는 동선 | AI 사진 매칭 결과 화면에 정정 진입점 추가 → 오매칭이 제보 데이터로 쌓이는 루프 | `user_submissions` 파이프라인 재활용 |
| 6 | **성분 신고/참고문헌 노출** | 첨가물 사전의 "참고문헌"과 "첨가물 신고하기"가 신뢰를 만든다 | 감미료 바텀시트에 출처 링크(이미 `docs/sugar-baselines.md`에 근거 정리됨)와 "정보 오류 신고" 추가 | `sweetener_review` 테이블 이미 존재, UI만 없음 |

### 2.2 기존 기능을 더 낫게 고칠 지점

| # | 항목 | 현재 상태 | 개선 방향 |
|---|---|---|---|
| 7 | **바코드 스캔 재활성화 + 커버리지 부트스트랩** | 코드 완성인데 `FeatureFlags.barcodeScan=false`로 숨김. 반면 랜딩페이지는 "바코드 스캔 5초"를 주력 홍보 — **약속과 제품이 불일치** | Unlabel처럼 바코드를 1차 진입으로 복귀시키되, 미등록 시 현행 촬영 제보 플로우로 자연 폴백. 커버리지는 **식약처 공공 바코드연계제품정보(무료)로 기본 영양성분을 부트스트랩**하고, 그 위에 우리만의 감미료 태깅(`product_sweeteners`) 레이어를 얹는 2층 전략. 코리안넷 유료 구매는 공공 API로 부족할 때 검토 |
| 8 | **"좋아요" 긍정 축 추가** | Verdict 이유 불릿이 사실상 감점 사유 중심 | Unlabel의 "아쉬워요/좋아요" 2축처럼 **잘한 점(단백질↑, 식이섬유↑, 알룰로스 사용, 위험 당알코올 없음)을 명시**. "겁주는 앱"이 아니라 "공정한 심판" 인상 — 룰북 신뢰도와 직결 |
| 9 | **데이터 검수 완결** | 전 제품 `verified=false`, 탄수<차감합 17건·감미료 미태깅 30건·null 11건·중복 6건 미해결 | Unlabel 커뮤니티 1위 글("검색하면 나오긴 하는데…")이 반면교사. **출시 전 408개 전수 검수**가 어떤 신기능보다 우선 |
| 10 | **제품 즐겨찾기** | 매장 즐겨찾기만 존재 | 제품에도 하트 추가(다시 살 제품 목록). 히스토리(#1)와 함께 재방문 루프 완성 |
| 11 | **양 조절 슬라이더 유지·강조** | 이미 보유(배수 조절 실시간 재계산) | Unlabel은 120g 고정 토글뿐이다. **우리가 더 잘하는 부분**이니 결과 화면에서 접힘 해제 등 노출 강화 |

### 2.3 의도적으로 도입하지 않을 것 (반면교사)

| 항목 | 이유 |
|---|---|
| **0~100 종합 점수** | 산정 근거가 불투명한 단일 숫자는 어그로에는 유리하나 방어가 불가능하다(Unlabel도 면책 문구로 회피). 우리의 신호등 + 이유 불릿 + 룰북 문서 공개가 장기 신뢰 자산. 숫자가 필요하면 "각설탕 N개" 환산처럼 **물리적 의미가 있는 숫자**만 쓴다 |
| **스캔 횟수 제한·초기 페이월** | 데이터가 얇은 초기 단계의 유료화는 커뮤니티 불만("유료임 무료임?")으로 직행. 우리 랜딩 약속("무료예요", "회원가입 없이 바로 스캔")을 지킨다. 수익화는 §2.4 |
| **범용 커뮤니티 게시판** | Unlabel 게시판도 좋아요 1~6개 유령도시. 우리는 제품 코멘트·매장 리뷰(맥락 있는 UGC)에 집중 |
| **첨가물 전 범주 확장** | 색소·보존료까지 넓히면 축이 희석되고 Unlabel의 홈그라운드에서 싸우게 된다. 감미료 28종 + 혈당 축을 지킨다 |
| **알레르기 필터 전면 도입** | 그들의 핵심 개인화 축이지만 우리 타깃(혈당·체중 관리)의 1순위 문제가 아니다. 중기 백로그로만 유지(표시정보 기반 정보성 노출 수준) |

### 2.4 수익화 관찰과 우리의 순서

Unlabel은 **구독 우선**(₩4,000~5,800/월, 핵심 기능 전부 게이팅)을 선택했고, 그 대가로 초기 신뢰를 지불하고 있다. 우리는 순서를 뒤집는다:

1. **지금**: 전면 무료 유지 → 데이터·리뷰·바이럴 축적 (Unlabel 대비 최대 차별화 메시지)
2. **다음**: 이미 있는 커머스 자산의 제휴 전환 — 핫딜·가격비교 링크에 제휴 파라미터(라라스윗/널담/마이노멀 공식몰 + 쿠팡파트너스), `deal_price_stats`(역대 최저가) UI 연결
3. **그 후**: 프리미엄은 "정보 게이팅"이 아니라 **"데이터 자산 기반 편의"**로 — 최저가 알림, 가격 이력 그래프, 개인화 리포트. 판정·스캔은 영원히 무료
4. 유료화 시점이 오면 Unlabel의 **결제 크래프트**(무료/유료 비교표, 하루 133원 프레이밍, 얼리버드 할인, 7일 체험)는 그대로 벤치마킹할 가치가 있다

## 3. 차별화 지점 — 우리가 이기는 자리

| 축 | Unlabel | ZERO DOT | 차별화 메시지 |
|---|---|---|---|
| **문제 정의** | 첨가물 전반 "무엇이 들었나" | **"무설탕·제로가 진짜인가"** — 혈당 영향 단일 축 | "제로의 팩트체커". 웰치 **제로**가 그들 앱에서 27점을 받아도 *왜*인지는 안 보인다. 우리는 "라벨은 0g → 몸은 혈당↑"를 이유 문장으로 설명한다 |
| **판정 방식** | 근거 비공개 0~100점 + 면책 문구 | **룰북 기반 런타임 계산**(순탄수 공식, 임계값, 함정 4종) + 이유 불릿 + 문서 공개, 409개 전수 재산출 리포트 보유 | "점수로 겁주지 않고, 계산식을 보여준다" |
| **데이터 깊이** | 표시정보 파싱(넓고 얕음) | **감미료 28종 × 함량(g) 태깅 896행 + 조합 규칙 12종**(말티톨 함정, 조합 카피) — 표시정보를 넘어선 가공 자산 | 코리안넷을 사면 누구나 그들처럼 만들 수 있지만, 우리 감미료 레이어는 못 만든다 |
| **행동 연결** | 정보 조회에서 끝 | 분석 → **대안 추천** → **저당맵**(매장 127곳+프랜차이즈 음료 1,290종, 각설탕 환산, 4개 국어) → **핫딜/가격비교** → **슈가포인트·먹은 기록** | "알았으면, 어디서 사고 뭘 마실지까지" — BEFORE(구매 전 확인) 포지셔닝 |
| **가격 정책** | 핵심 기능 유료(월 5,800원), 스캔 7회 제한 | 전면 무료, 가입 없이 스캔 | 초기 시장에서 가장 강한 한 줄: "우리는 다 무료" |
| **성장 루프** | 구매한 DB (정적) | 사용자 제보 → AI 파싱 → 관리자 검수 승격 (자라는 DB) | 커버리지는 뒤지지만 데이터 신선도·소유권에서 앞선다 |
| **지역·확장 자산** | 없음 | 전주 기반 저당맵 + 한/영/일/중 다국어 | 지역 밀착·관광객 확장이라는 그들에게 없는 면 |

**전략 한 줄**: Unlabel이 "식품계의 화해(성분 사전)"라면, ZERO DOT은 "제로식품계의 팩트체커 + 내비게이션"이다. 커버리지 싸움(그들의 링)으로 끌려가지 말고, "제로/저당을 사는 순간"이라는 좁은 맥락의 모든 단계(판정→대안→구매처→보상)를 장악한다.

## 4. 마케팅 계획 — 인스타그램 벤치마킹

### 4.1 왜 통했는지 분해

1. **포맷**: AI 제품 의인화 캐릭터가 1인칭으로 자백하는 릴스 — 폭로 콘텐츠인데 귀엽다. 불쾌감 없이 공유된다
2. **훅**: "대기업이 속인 제품 TOP 4" — 분노+호기심을 3초 안에 점화
3. **시리즈물**: "(N편)" 넘버링 — 다음 편 기대가 팔로우 사유가 된다
4. **제작 경제성**: AI 생성이라 게시물당 비용·시간이 낮고 템플릿이 고정되어 양산 가능. 게시물 5개로 2.2만 팔로워는 포맷의 승리
5. **페르소나 분리**: 앱 공식 계정이 아닌 "까발려주마" 캐릭터 계정 → 브랜드 안전과 무관하게 수위 조절 가능, 프로필 링크 1개로 퍼널 단순화

**그들의 리스크(우리는 피할 것)**: ① "속인"이라는 단정 표현 + 실명 브랜드 = 명예훼손·업무방해 소지 ② 실제 패키지를 본뜬 AI 캐릭터 = 상표·트레이드드레스 소지 ③ 조회수 대비 팔로워 전환이 낮은 탐색 트래픽 의존 ④ 유입된 기대치를 앱 품질(유료화·데이터 불만)이 못 받치는 중

### 4.2 ZERO DOT 콘텐츠 전략

**계정 구조**: 바이럴 페르소나 계정(신규) + 브랜드 계정(공지·스토어용) 분리. 페르소나 콘셉트 예: **"제로수사대"** — 제로/무설탕 제품만 취조하는 수사관 캐릭터. 프로필 링크는 랜딩(`landing/index.html`) 하나만.

**톤 가드레일(법무)**: "속였다/사기" 금지 → **"라벨은 0, 혈당은 0이 아니에요"** 프레임. 모든 주장에 표시정보 수치 인용(나트륨 1930mg처럼), 판정은 "룰북 기준 등급" 명시. 패키지는 실물 촬영 인용 또는 특정 상표가 식별되지 않는 수준의 캐릭터화. 이 톤은 우리 랜딩 카피("라벨의 0은 혈당의 0이 아니에요")와 이미 일치한다.

**콘텐츠 필러 4개** (모두 우리만 가진 데이터에서 나온다):

| 필러 | 포맷 | 데이터 소스 |
|---|---|---|
| ① **"제로의 배신" TOP4 (시리즈)** | 무설탕·제로 표기인데 룰북 '주의' 등급 — 말티톨/칼로리 함정 자백 릴스. 시그니처 시리즈, 넘버링 필수 | 룰북 함정 4종 + 🔴 155개 제품 풀 |
| ② **"의외로 무죄" TOP4 (역시리즈)** | 제로인데 진짜 괜찮은 제품 조명 — 폭로 일변도인 Unlabel과 차별화, 균형 = 신뢰 + 브랜드 리스크 헤지 | 🟢 183개 제품 풀, 알룰로스·에리스리톨 조합 |
| ③ **각설탕 환산 비주얼** | "이 프랜차이즈 음료 = 각설탕 N개" 스택 쌓기, 브랜드 간 동일 메뉴 비교 | `franchise_drinks` 1,290행 + `sugar_cubes` 환산(그들에게 없는 데이터) |
| ④ **대체당 1분 사전** | "에리스리톨+스테비아, 왜 세트로 다닐까" 같은 조합 스토리 | `sweeteners` 28종 + `combo_rules` 12종 카피 자산 |

**제작 파이프라인**: 검증된 템플릿 고정(상단 컬러 타이틀 박스 + 캐릭터 + 하단 한 줄 자막) → AI 이미지·영상 생성 → 자막·컷 편집. 주 2회 × 4주 = 8개로 파일럿. 1편은 가장 어그로가 강한 ①로 시작.

### 4.3 퍼널 — 이미 깔린 인프라에 연결

```
릴스 (탐색 트래픽) → 프로필 링크 → 랜딩 (landing/index.html)
  → 출시 알림 신청 (launch_notifications 테이블, 이미 구현됨)
  → 출시 시 이메일/문자 → 다운로드
  → 앱 내 공유 카드(§2.1-#2) → 다시 릴스/스토리 소재로 (루프 완성)
```

- 링크에 UTM 파라미터, 랜딩에 방문 계측(GA4 또는 Vercel Analytics) 추가 필요 — 현재 계측 없음
- 출시 전에는 "출시 알림 N명" 자체를 콘텐츠로 활용 가능("수사 지원자 모집")

### 4.4 4주 파일럿 플랜과 KPI

| 주차 | 콘텐츠 | 목표 |
|---|---|---|
| 1주 | ①제로의 배신 1편 + ③각설탕 스택 1편 | 포맷 반응 테스트(후킹 3초 유지율) |

| 4주 | ①4편 + ③2편(브랜드 대결) | 최고 성과 포맷에 리소스 집중 결정 |

**KPI(파일럿 종료 기준선)**: 릴스 평균 조회 3만+ / 1개 이상 10만+ 히트 / 팔로워 2천+ / 랜딩 유입 CTR 1% / 출시 알림 신청 300+. Unlabel의 5개→2.2만이 상단 벤치마크이며, 절반 수준이어도 포맷 검증으로 간주하고 지속.
